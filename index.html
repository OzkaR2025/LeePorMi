Política de Privacidad de LeePorMí

Última actualización: 2026

1. Compromiso de Privacidad

LeePorMí es una aplicación de accesibilidad diseñada para la lectura de pantalla en voz alta. Nos tomamos la privacidad de nuestros usuarios con la máxima gravedad. No recopilamos, almacenamos ni compartimos ningún tipo de datos personales o contenidos de pantalla.

2. Procesamiento de Datos Local (On-Device)

Todo el procesamiento de reconocimiento óptico de caracteres (OCR mediante Google ML Kit) y la síntesis de texto a voz (TTS) se ejecutan de forma 100% local en el dispositivo del usuario. Las capturas de pantalla utilizadas para extraer texto se procesan de forma efímera en la memoria RAM y no se guardan ni transmiten externamente.

3. Permisos Requeridos y su Uso

La aplicación requiere los siguientes permisos únicamente para su funcionamiento en el dispositivo:

  • Servicio de Accesibilidad: Utilizado exclusivamente para acceder al contenido textual de la pantalla activa cuando el usuario interactúa con la aplicación o pulsa el botón "LEER".
  • Superposición sobre otras aplicaciones: Necesario para mostrar los botones flotantes de lectura y configuración sobre la interfaz del sistema.

4. Servicios de Terceros y Publicidad

La aplicación no contiene publicidad de terceros, herramientas de análisis de comportamiento ni rastreadores.
